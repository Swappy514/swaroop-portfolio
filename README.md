## ✨ What Makes This Different

- 🎬 **Cinematic intro** — iris wipe boot animation on every load
- 🌀 **Orbit system** — 8 tech icons orbit around the hero content
- 🎨 **Dual theme** — dark sections alternate with cream light sections
- 🖱️ **Custom cursor** — gradient dot with animated trailing ring
- 📝 **Auto blog sync** — Hashnode GraphQL API fetches posts automatically
- 🔍 **Active nav** — navbar highlights current section while scrolling
- 📊 **Real projects** — actual screenshots, not placeholder mockups
- 📧 **Working contact** — Nodemailer sends real emails via Gmail

## 🚀 Getting Started

### Prerequisites
```
node  v18 or higher
npm   v9 or higher
```

### Run Locally

```bash
# Clone the repo
git clone https://github.com/Swappy514/swaroop-portfolio.git

# Install dependencies
cd swaroop-portfolio
npm install

# Set up environment variables
cp .env.example .env.local
# Fill in EMAIL_USER and EMAIL_PASS

# Start development server
npm run dev
```

Open `http://localhost:3000`

---

## 🔐 Environment Variables

```env
EMAIL_USER=your.gmail@gmail.com
EMAIL_PASS=your_16_char_app_password
```

To get your Gmail App Password:
1. Google Account → Security → 2-Step Verification → ON
2. Security → App Passwords → type any name → Create
3. Copy the 16-character password

> `.env.local` is in `.gitignore` — your credentials are never uploaded to GitHub.

## 📦 Deploy Your Own

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Swappy514/swaroop-portfolio)

1. Click the button above
2. Add `EMAIL_USER` and `EMAIL_PASS` in Vercel Environment Variables
3. Deploy — done in 2 minutes
