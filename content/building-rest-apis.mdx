# Building Scalable REST APIs With Node.js & Express

Building a REST API that works in development is easy. Building one that scales in production is a different story entirely.

## Project Structure

A well-structured Express app uses separation of concerns — routes, controllers, middleware and models all in their own folders.

## Error Handling

Always use a centralized error handler. Never let unhandled errors crash your server.

## MongoDB Best Practices

Use indexes on frequently queried fields. Use aggregation pipelines for complex queries instead of multiple round trips.
